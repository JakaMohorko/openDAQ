How the proposal was made

Audiences

  • application: applications, modules and the core. Written [api(application)] because RTGen's lexer treats public as a keyword.
  • module: modules and the core, never applications.
  • core: the core only; free to change in any release.
  • inherit (methods only): the method follows its interface. Only methods that differ carry a tag.

Interfaces

  • Coretypes are the kinds of value the CoreType enum names, which property values, arguments, container elements and struct fields hold: . A predefined struct such as IArgumentInfo reports ctStruct and is not a coretype itself.
  • A name or header ending in Private/Internal is module when a scanned module uses it, otherwise core.
  • Everything else is application unless a reason on the row says otherwise.

Implementation members

  • Only non-private members of classes modules derive from (or their bases) are listed; interface overrides follow the interface and are not listed.
  • Overridden by a module, or a virtual on* hook: module, override. Called by a module: module. A variable written by a module: module; only read: module, readOnly. Anything else: core.

Factories

  • INTERNAL_FACTORY (not exported): core. Component constructors taking a context and a parent: module. Otherwise the audience of the returned interface.
  • Evidence tags: A applications, M modules, D documentation, T integration tests. Only A and M decide proposals. Sources: the openDAQ examples and Python GUI, the openDAQ organization's modules and applications (local clones, plus shallow clones of the rest), the knowledge base and the reference docs.
